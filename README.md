# Retail-Sales-Data-cleaning
Retail Sales Data Cleaning Project

Project Overview

This project focuses on cleaning and preprocessing a retail sales dataset using Python and Pandas.

The main objective is to improve data quality by identifying and handling missing values, duplicate records, inconsistent data formats, and outliers.

Objectives

- Identify missing values and duplicate records.
- Handle missing values using median imputation.
- Remove duplicate records.
- Standardize gender values.
- Convert date columns into datetime format.
- Detect and handle outliers using the IQR method.
- Validate the cleaned dataset.
- Export the cleaned data into a CSV file.

Tools & Technologies

- NumPy

Project Workflow

1. Data Loading

5. Data Standardization

7. Before-and-After Data Validation
8. Exporting Cleaned Dataset

Dataset Information

This project uses a small synthetic retail sales dataset created for learning and demonstration purposes.

- Original records: 6
- Final cleaned records: 5
- Missing values handled: 2
- Duplicate records removed: 1

An artificial sales anomaly was introduced to demonstrate the IQR outlier-handling method.

Files Included

- "01_DATA_CLEANING.ipynb" – Jupyter Notebook containing the complete data cleaning process.
- "cleaned_retail_data.csv" – Final cleaned dataset.
